
# DevOps Survival Roadmap

A structured, beginner-friendly guide to learning DevOps from the ground up.

This repository brings together learning notes, explanations, command references, hands-on exercises, configuration examples, scripts, and interview-preparation material.

It is designed for **absolute beginners** who want to build a strong foundation and gradually develop practical DevOps skills.

No prior DevOps experience is required. Start with the fundamentals, practise each topic, and progress through automation, cloud infrastructure, and container orchestration.

---

## What You'll Learn

The roadmap follows a practical learning sequence:

| Area | Topics Covered |
|---|---|
| **Linux Administration** | Linux fundamentals, file systems, permissions, shell scripting, process and service management |
| **Networking** | OSI model, IP addressing, subnetting, TCP/UDP, routing, and network fundamentals |
| **Web & Server Administration** | HTTP, Apache, Nginx, server setup, and reverse proxies |
| **Version Control** | Git, GitHub, branching strategies, and collaboration workflows |
| **Containerization** | Docker, images, containers, volumes, Docker Compose, and container management |
| **CI/CD** | Jenkins, pipelines, agents, webhooks, and deployment automation |
| **DevSecOps** | Static code analysis, vulnerability scanning, and security integration |
| **Cloud Computing** | AWS compute, storage, networking, databases, messaging, and serverless services |
| **Infrastructure as Code** | Terraform, CloudFormation, state management, modules, and infrastructure automation |
| **Configuration Management** | Ansible, playbooks, inventory, and system provisioning |
| **Container Orchestration** | Kubernetes architecture, workloads, services, storage, namespaces, and resource management |

The repository also includes scenario-based interview questions and answers to help reinforce your understanding.

---

## How to Use This Repository

If you're starting from zero, follow this approach:

1. **Begin with Linux.** Open [Week 01: Linux Fundamentals](./Week-01-Linux-Fundamentals/) and work through the topics in order.
2. **Follow the learning sequence.** Continue through networking, server administration, Git, Docker, Jenkins, and the remaining sections.
3. **Understand before moving ahead.** Read the notes and make sure you understand the purpose of each concept and command.
4. **Practise in a lab environment.** Run the commands, follow the examples, and build the configurations yourself.
5. **Explore the practical files.** Look through the folders for scripts, configuration files, command references, and implementation examples.
6. **Revise with interview questions.** Use the [Interview Questions and Answers](./Interview-Questions-and-Answers/) directory to test your understanding and practise real-world scenarios.

**Recommended learning method:** Read a topic, practise it, experiment with it, and troubleshoot it. Avoid simply copying commands without understanding what they do.

The repository is organized by learning area. Each topic has its own directory containing the relevant notes and practical material.

## Getting Started

You can browse the repository directly on GitHub or clone it locally:

```bash
git clone https://github.com/hridyen/DevOps-Survival-Roadmap.git
cd DevOps-Survival-Roadmap
```

Open the first learning folder and begin with the fundamentals. Use your preferred terminal, virtual machine, or local lab environment to practise the examples.

---

## A Note for Beginners

You do not need to learn every tool at once. Build your understanding one concept at a time, practise consistently, and revisit topics whenever necessary.

DevOps is best learned through hands-on experience: build, test, troubleshoot, and improve.

Use this roadmap as a learning companion throughout your DevOps journey.
